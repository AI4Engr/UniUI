# Project Instructions for Claude

## Legacy Backends Notice

The `wxPython` and `Tkinter` (tk) backends in this project are officially **legacy** and **unsupported**.

### Rules for Development:
- **DO NOT** implement new widgets, features, or design enhancements for the `wx` or `tk` backends.
- All new features and component updates must only target **Qt** (`src/uniui/qt.py`) and **Jupyter** (`src/uniui/jupyter.py`).
- If asked to modify `wx.py` or `tk.py`, explain that they are legacy and decline development on them (except for critical security or backward compatibility bugs if explicitly ordered by the user).
